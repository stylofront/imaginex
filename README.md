# imaginex

> **100% Client-Side Image Transformation & Optimization Studio**  
> Built with Next.js 16, Tailwind CSS v4, WebAssembly, and multi-threaded Web Workers.  
> Created by [Styloshare Team](https://www.styloshare.com) • [imaginex.styloshare.com](https://imaginex.styloshare.com)

---

## ⚡ Features & Tools

Imaginex processes 100% of image pixel manipulation in your local browser memory. Zero files are uploaded to cloud servers, guaranteeing complete privacy and NDA compliance.

* 🔄 **Format Converter**: Lossless & lossy conversion across WEBP, PNG, JPEG, AVIF, BMP, and GIF.
* 🗜️ **Smart Compressor**: High-ratio image compression with Target KB sizing and Core Web Vitals optimization.
* 📐 **Lanczos3 Resizer**: Sub-pixel sinc mathematical interpolation for sharp downscaling without blur.
* ✂️ **AI Background Remover**: Local browser neural segmentation with transparent alpha channel exports.
* 🗂️ **Batch Studio**: Multi-threaded Web Worker queues with instant bundled ZIP export.
* 🔍 **Visual Diff Slider**: Side-by-side interactive comparison matrix with magnification loupe.
* 🎨 **Color Palette Harvester**: Dominant harmony extraction with HEX and Tailwind CSS palette generator.
* 🛡️ **EXIF & GPS Inspector**: Audit and sanitize embedded camera telemetry, GPS coordinates, and device metadata.
* ✂️ **Interactive Cropper**: Freeform and social media aspect ratio cropping presets.
* 💧 **Watermark Studio**: Text and logo branding stamps with opacity and tiling controls.
* 🎛️ **Cinematic Filters**: Canvas shaders, duotones, and color balance controls.
* 📱 **PWA Offline Mode**: Fully installable Progressive Web App with service worker caching.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/stylofront/imaginex.git

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build

```bash
npm run build
npm run start
```
